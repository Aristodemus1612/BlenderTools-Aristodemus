# ConverterPIX

These are unmodified builds of **ConverterPIX** by mwl4, used by
**File > Import > SCS Models from Game Archives (*.scs)**.

- Source code: https://github.com/mwl4/ConverterPIX
- Builds taken from commit `3cd4e73a86d0c6bd28e117664c50a36cabeccf38` (2025-06-25),
  folders `bin/win_x64`, `bin/win_x86` and `bin/linux`.
- Licence: GNU Lesser General Public License, version 3 (`COPYING.LESSER`), which builds on the
  GNU General Public License, version 3 (`../LICENSE`).

No macOS build is included. On macOS the importer downloads one the first time it is used.
